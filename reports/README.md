# Reports

- [`report.md`](report.md) — the report of record: a fresh, professional write-up of
  the study with embedded figures. This replaces the original PDF/PPTX, which are
  not published.
- [`limitations.md`](limitations.md) — honest limitations and next steps.
- [`figures/`](figures/) — the curated figure set and its [manifest](figures/README.md).
- [`maps/launch_sites.html`](maps/launch_sites.html) — the interactive Folium map of
  launch sites and launch outcomes.

Figure and map assets are regenerated from `data/processed/` by
`scripts/make_figures.py`; see the [figure manifest](figures/README.md) for the
mapping from each image to its source data.
