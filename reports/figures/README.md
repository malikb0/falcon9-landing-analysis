# Figure manifest

All charts except the two screenshots are regenerated from `data/processed/` by
`scripts/make_figures.py` (seaborn `whitegrid`, 150 dpi, `bbox_inches='tight'`).
Run that script from the repository root to reproduce them.

| Figure | Shows | Source data |
|--------|-------|-------------|
| `01-outcome-distribution.png` | Count of failed vs. successful first-stage landings | `spacex_launch_geo.csv` |
| `02-flight-number-vs-payload-mass.png` | Payload mass against flight number, coloured by outcome | `spacex_launch_geo.csv` |
| `03-flight-number-vs-launch-site.png` | When each launch site was used, coloured by outcome | `spacex_launch_geo.csv` |
| `04-success-rate-by-orbit.png` | Average landing success rate per orbit family | `spacex_launch_geo.csv` |
| `05-yearly-success-trend.png` | Average landing success rate by launch year | `spacex_launch_geo.csv` |
| `06-payload-mass-vs-launch-site.png` | Payload-mass distribution for each launch site | `spacex_launch_geo.csv` |
| `07-model-evaluation-scores.png` | Accuracy, precision, recall, F1 and AUC for the four classifiers | `dataset_part_2.csv`, `dataset_part_3.csv` |
| `08-confusion-matrices.png` | Confusion matrices for the four classifiers on the test set | `dataset_part_2.csv`, `dataset_part_3.csv` |
| `09-success-rate-by-launch-site.png` | Average landing success rate per launch site | `spacex_launch_geo.csv` |
| `10-folium-launch-sites-map.png` | Screenshot of the interactive Folium map with proximity distances | owner's archived map output (see `../maps/launch_sites.html` for the interactive version) |
| `11-dashboard.png` | Screenshot of the Plotly Dash dashboard | owner's archived dashboard output (see `../../dashboard/app.py`) |

Notes:

- Figures `01`–`06` and `09` describe the 56-launch launch-site dataset
  (2010–2018); figures `07`–`08` describe the 90-launch modelling dataset
  (2010–2020). The two sources differ in coverage — see `../limitations.md`.
- The interactive map itself is committed at `../maps/launch_sites.html` and is
  regenerated by `scripts/make_figures.py`.
